# Space-Breakers

Space-Breakers is a 2D incremental game where a ball
bounces around the screen, breaking blocks and earning points. The game features various power-ups and upgrades that players can purchase to enhance their gameplay experience. The objective is to break as many blocks as possible while avoiding obstacles and collecting bonuses.

```bash
g++ -std=c++17 main.cpp -o space_breakers -lsfml-graphics -lsfml-window -lsfml-system
```
